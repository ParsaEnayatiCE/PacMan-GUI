# PacMan GUI

A classic Pac-Man clone built with **Java** and **JavaFX**. The game features a full menu flow (main menu → level select → gameplay → win/lose screen), three selectable maze layouts loaded from plain-text level files, two AI-controlled ghosts that chase the player, a "power dot" mode that lets Pac-Man eat the ghosts, background music, and score tracking.

## Features

- **Main menu, level select, and end-game screens** built with JavaFX FXML views (`start.fxml`, `levels.fxml`, `game_play.fxml`, `gameOver.fxml`, `youWon.fxml`)
- **Three playable levels** (`level1.txt`, `level2.txt`, `level3.txt`), each defined as a text-based grid map that is parsed at runtime
- **Grid-based movement** for Pac-Man with wall collision detection and direction buffering (continues in the last valid direction when a new key press would hit a wall)
- **Two chasing ghosts** with simple, deterministic AI: when a ghost shares a row or column with Pac-Man it moves directly toward (or, in power mode, away from) him; otherwise it continues on its current heading and picks a random open direction whenever it hits a wall
- **Power dots ("big dots")**: eating one flips the game into *ghost-eating mode* for a fixed number of ticks, during which the ghosts turn blue, flee from Pac-Man, and are sent back to their home tile if caught
- **Score system**: +5 points per small dot eaten
- **Win/lose conditions**: the game ends in victory when every dot on the level has been collected, and ends in defeat if Pac-Man collides with a ghost outside of power mode
- **Screen wrapping**: moving off the left/right edge of the maze wraps Pac-Man (and the ghosts) around to the opposite side
- **Background music** with mute (`M`) and pause/resume (`P`) controls
- **Instant restart** (`R`) without relaunching the app
- Sprite-based rendering using animated GIFs for Pac-Man (facing up/down/left/right) and the ghosts (normal + "eaten/blue" state)

## Tech Stack / Built With

- **Language:** Java (JDK 8 / language level `1.8`)
- **UI Framework:** JavaFX (FXML views + CSS styling), using `javafx.application.Application` as the entry point
- **Media:** `javafx.scene.media` for MP3 background music playback
- **Project layout:** plain IntelliJ IDEA project (no Maven/Gradle build script) — source lives directly under `src/`, and a custom `javafx.geometry.Point` helper class is vendored into the project for 2D vector math
- **Game loop:** a `java.util.Timer`/`TimerTask` driving fixed-rate updates (5 frames per second) on the JavaFX application thread via `Platform.runLater`
- **Data format:** levels are stored as whitespace-separated text grids and parsed with `java.util.Scanner`

## Prerequisites

- **JDK 8** (the project's language level is explicitly set to `1.8`; JavaFX was bundled with the Oracle JDK up through Java 8). To run on a newer JDK (11+), you'll need a JDK distribution that bundles JavaFX (e.g. Liberica Full JDK) or add the [OpenJFX](https://openjfx.io/) SDK to the module/classpath yourself.
- **IntelliJ IDEA** (recommended) — the repository includes IntelliJ project metadata (`.idea/`, `PACMAN-GAME.iml`) and a pre-configured JavaFX artifact, making it the easiest way to build and run the project.

## Installation & Setup

### Option 1: IntelliJ IDEA (recommended)

1. Clone the repository:
   ```bash
   git clone https://github.com/ParsaEnayatiCE/pacman-gui.git
   ```
2. Open the project folder in IntelliJ IDEA — it will pick up the existing `.iml` module and project SDK settings.
3. Set the Project SDK to a JDK 8 (or a JavaFX-bundled JDK) under *File → Project Structure*.
4. Run the `sample.Main` class (right-click → *Run 'Main.main()'*), or build the pre-configured `PACMAN-GAME` JavaFX artifact via *Build → Build Artifacts*.

### Option 2: Command line

```bash
git clone https://github.com/ParsaEnayatiCE/pacman-gui.git
cd pacman-gui

# Compile (requires a JDK that includes/links JavaFX, e.g. Liberica Full JDK 8/11)
javac -d out/production/PACMAN-GAME $(find src -name "*.java")

# Run from the repository root (levels are loaded via the relative path "src/levels/...")
java -cp out/production/PACMAN-GAME:src sample.Main
```

> **Note:** `Model.initializeLevel` and `GamePlayController.initialize` load the level files and music track using paths relative to the working directory (`src/levels/...`, `src\sample\mp3\song.mp3`), so run the game from the repository root so these assets resolve correctly.

## How to Play

1. Launch the game and click **PLAYER VS COMPUTER** on the main menu.
2. Pick one of the three levels on the level-select screen.
3. Guide Pac-Man around the maze, eating dots for points while avoiding the two ghosts.
4. Grab a **big dot** to enter power mode — the ghosts turn blue and flee, and touching them sends them back to their spawn point.
5. Clear every dot on the board to win, or lose if a ghost catches you outside of power mode.

**Controls:**

| Key | Action |
|-----|--------|
| Arrow keys (`↑ ↓ ← →`) | Move Pac-Man |
| `P` | Pause / resume |
| `M` | Mute / unmute music |
| `R` | Restart the current level |
| `Esc` | Quit the game |

## Implementation Notes

- **Movement & collision** are grid-based: `Model.movePacman` computes a candidate cell from the requested direction, falls back to continuing in the last direction if the new one is blocked by a wall, and otherwise stops in place.
- **Ghost AI** (`Model.moveAGhost`) is a simple line-of-sight chase: if a ghost shares Pac-Man's row or column, it steers directly toward him (or away, when in power/ghost-eating mode); otherwise it keeps its current velocity and, on hitting a wall, picks a new random direction until it finds an open path.
- **Power mode** is time-boxed via a countdown counter (`ghostEatingModeCounter`, reset to 25 ticks per big dot) managed by `GamePlayController` and checked each game-loop tick.
- **Level data** is decoupled from code — each level is a simple text grid, so new mazes can be added without touching the `Model`/`View` logic, as long as the symbol legend (`W`, `S`, `B`, `1`, `2`, `P`, blank = empty) is followed.
